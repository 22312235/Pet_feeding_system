# 🌐 Frontend Documentation

## Purpose

The frontend provides an intuitive interface allowing users to interact with the Smart Pet Feeder remotely.

## Responsibilities

- Display pet information
- Feed immediately
- Schedule meals
- Cancel meals
- Display current status
- Validate user input
- Communicate with Supabase

## Technologies

- HTML
- CSS
- JavaScript
