# 🤖 ESP32 Firmware

## Purpose

The ESP32 is responsible for executing feeding requests stored in the cloud database.

## Responsibilities

- Connect to WiFi
- Query Supabase
- Detect pending requests
- Activate relay
- Rotate servo motor
- Dispense food
- Update feeding status

## Hardware

ESP32

Servo Motor

Relay Module

Power Supply

## Libraries

WiFi

HTTPClient

ArduinoJson

ESP32Servo
